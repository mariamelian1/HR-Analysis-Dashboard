# HR Analysis Dashboard

An interactive HR dashboard built using Microsoft Excel to analyze employee performance, salaries, satisfaction scores, training costs, and absence days.

## Features

* Interactive slicers
* KPI cards
* Multi-page dashboard
* Employee insights by department and job role
* Data visualization using Pivot Charts

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
